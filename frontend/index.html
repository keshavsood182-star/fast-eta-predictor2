01 · Problem

Predict the delivery time at the moment the order is placed.

Target: Time_taken (min). The model may only use information that exists at prediction time — nothing that happens after the order is placed.

02 · Dataset

45,584 deliveries. 44 days.

20 original columns, covering 2022-02-11 → 2022-04-06. Real operational data — which means real operational mess.

Columns with important missing values

Delivery_person_RatingsDelivery_person_AgeTime_OrderdCitymultiple_deliveriesWeather_conditionsRoad_traffic_densityFestival

03 · Cleaning

Fix what is wrong. Delete as little as possible.

Ratings

53 ratings fell outside the valid 1–5 range. They were set to missing rather than deleting the orders.

GPS

3,640 records had a coordinate with absolute value < 0.1. They were kept: GPS_valid = 0, coordinates → NaN.

05 · Leakage

We cannot use the future to predict the present.

ORDER PLACED
Weather · Traffic · Distance · Vehicle · Courier · Order time
PREDICTION
happens here
DELIVERY
Time_Order_picked occurs AFTER the order is placed. Using it would leak future information. Excluded.

Raw IDs were also not used as predictive features.

Tuning (lightweight 3-fold CV search) lowered validation RMSE from 4.184 to 4.058 — a 3.01% improvement. Final parameters: n_estimators=150, max_depth=15, min_samples_leaf=1, min_samples_split=2, max_features=0.5, random_state=42.
